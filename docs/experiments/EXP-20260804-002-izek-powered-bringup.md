# EXP-20260804-002: Historical IZEK powered bring-up

## Record type

Historical reconstruction created 2026-08-04. Exact bench date not yet recovered.

## Objective

Preserve the first powered functional check of the Singer IZEK and define the boundary between motor/needle motion and validated sewing operation.

## Hardware

- Singer IZEK 1500
- replacement foot controller purchased from Amazon
- no original cartridge recorded as present
- no Game Boy communication hardware involved in this check

## Procedure retained from history

1. Connect replacement foot controller.
2. Power the machine.
3. Operate the controller.
4. Observe basic sewing-machine functionality.

## Observed result retained from history

The replacement foot controller operated the machine and basic powered sewing-machine function was observed.

Classification: `observed/reported`.

## Explicit claim boundary

This result does not establish:

- correct threading;
- correct bobbin class or orientation;
- correct spool/thread selection;
- valid tension;
- feed under fabric load;
- formation of a lockstitch;
- sustained operation;
- controller electrical equivalence to the original part;
- Game Boy or IZEK protocol functionality.

## Decision produced by the experiment

Validation sequence:

1. prove ordinary sewing-machine operation;
2. prove operation with intended Game Boy hardware or a technically justified facsimile;
3. observe and capture communication;
4. decode or implement only after evidence exists.

## Required follow-up experiment

- identify needle, thread, bobbin, and threading procedure;
- record controller model and ratings;
- produce one straight stitched seam on scrap fabric;
- photograph both sides of the seam;
- record video with machine settings visible;
- note skipped stitches, jams, tension problems, or feed failures.
